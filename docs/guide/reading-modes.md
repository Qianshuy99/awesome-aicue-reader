# 阅读模式与工作区

## 四种显示形态

| 形态 | 适用场景 | 可用位置 |
| --- | --- | --- |
| 浮窗 `floating` | 边看列表边读，位置和尺寸可自定义 | 列表页、详情页 |
| 全屏 `fullpage` | 长帖连续阅读 | 列表页、详情页 |
| 左嵌入 `embed-left` | 列表在右、正文在左 | 仅列表页 |
| 右嵌入 `embed-right` | 列表在左、正文在右 | 仅列表页 |

列表页四种形态都可用；直接打开讨论详情页时只有浮窗和全屏，因为嵌入形态需要宿主列表作为另一栏。

浮窗的长宽与左上角坐标保存在设置中，拖动或缩放后自动同步。在其他形态下修改浮窗尺寸，会在切回浮窗后生效。

## 工作区结构

工作区分为五个区域：顶部工具条、正文流、右侧时间轴、底部操作条，以及按需出现的侧栏（通知、历史、收藏等）。五区比例在布局设置中统一配置，四种形态共用同一套比例，元素再按容器实际宽度重排，因此窄浮窗和全屏下的排布会不同。

## 长帖如何加载

正文不会一次性渲染整帖。阅读器维护一个稳定的挂载区间，只把当前视口附近的楼层保留在 DOM 中，滚动时区间随之平移，离开区间的楼层被移除。这样长帖的 DOM 规模保持有界，代价是回滚到远处楼层时需要重新取数。

取数和渲染是两件独立的事：

- 预取决定“产生多少请求”，由性能设置中的需求项控制。
- 渲染窗口决定“同时保留多少 DOM”。
- 共享调度决定“请求何时发出”，负责排队、预算与限流退避。

三者都在性能设置里，预设从保守到激进。把预取调得过大时，调度层只能排队，不能抵消掉多出来的请求量。详见[设置中心总览](/settings/overview)。

## 阅读位置

切换形态、打开侧栏或返回上一帖时，阅读器保持当前楼层位置，不会跳回帖首。是否从首楼打开新帖可在[其他功能](/settings/other)中设置。
