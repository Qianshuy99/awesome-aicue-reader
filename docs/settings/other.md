# 其他功能

这一面板集中放历史导航、帖子打开方式和回复展示三类偏好，修改后自动保存在当前浏览器。

## 历史导航

| 设置 | 说明 |
| --- | --- |
| 边缘触发区域 | 以工作区宽度百分比表示，指针进入该区域时浮出左右导航按钮 |
| 长显左右按钮 | 始终显示左右按钮，开启后不再使用边缘触发区域 |
| 历史排序 | 控制历史列表的排列顺序 |

触发区域设得过大时，正常阅读中也容易误触按钮；设得过小则不易唤出。默认值在两者之间，按习惯微调即可。

## 帖子打开位置

从首楼打开：开启后，每次打开新帖都从第 1 楼开始；关闭时沿用站点自身的定位（通常是上次读到的位置或第一条未读）。

习惯从头读长帖的人建议开启；追更为主的人建议关闭。

## 回复展示

默认展开楼中楼：开启后，含引用关系的楼层在渲染时就展开被回复内容，省一次点击，代价是长帖 DOM 更重、滚动更耗资源。

楼中楼关系依赖正文中的提及标记推断，Flarum 没有回复目标字段。因此这个开关只影响“已识别到的关系”是否默认展开，不会让未携带提及的回复变得可识别。详见[楼层、时间轴与历史](/guide/navigation)。

## 与上游的差异

上游同一面板中还有自定义站点管理和 Boost 文案设置。本项目是言灵工坊单站点，没有自定义站点入口；Boost 属于 Discourse 插件能力，在本项目中关闭，相关设置行不渲染。
