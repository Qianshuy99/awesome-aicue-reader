# 设置中心总览

设置入口在工作区顶部。所有设置随改随存，保存在当前浏览器的脚本存储中，不上传。

## 面板一览

![设置中心的面板导航](/screenshots/14-settings-overview.png)

| 面板 | 职责 |
| --- | --- |
| 用户信息 | 查看当前账号资料与社区统计 |
| 图片设置 | 灯箱行为、帖内图片比例 |
| 字体设置 | 界面、正文、回复的字体与渲染参数，可扩展到宿主页面 |
| 布局设置 | 五区比例，四种形态共用 |
| 浮窗设置 | 浮窗长宽与左上角坐标 |
| 外观设置 | 颜色、粗细、圆角，自动生成明暗主题适应色 |
| 闪烁动效 | 跳转楼层的闪烁提示、等待区域动画 |
| 性能设置 | 预取需求、DOM 窗口、共享调度 |
| 资源监控 | 长任务、长帧、DOM 变更、网络活动的实时快照 |
| 请求数据 | 请求账本、优先级、限流状态与日志 |
| 其他功能 | 历史导航、帖子打开位置、回复展示 |
| 数据管理 | 设置导入导出、本地缓存清理 |
| 关于 | 版本、项目链接与致谢 |

## 性能设置的三层关系

![性能设置面板](/screenshots/15-performance-settings.png)

性能设置按“先需求、后调度”组织，理解这个顺序才能有效调参：

1. 需求层决定产生多少请求与多少 DOM，包括主楼层取数量和楼中楼自动请求。
2. 渲染层只管同时保留多少楼层在 DOM 中，与请求量无关。
3. 调度层负责排队、双窗口预算、429 退避与恢复探测。

调度层不会抵消过大的需求。如果预取量设得很高，调度只能把请求排得更久，页面反而更慢。卡顿时先降需求，再看渲染窗口。

性能设置在下次打开阅读器时生效，不影响当前已打开的工作区。

## 观测口径

资源监控与请求数据用于自查，两者口径不同：

- 资源监控每秒快照一次，长任务和网络事件按浏览器原始事件记录到毫秒，仅保留当前页面内存中的最近 10 分钟。标签页转入后台被节流时保留真实空档，不补造样本。
- 请求数据是同源标签页共享的账本，涵盖阅读器与宿主 API 的 10 秒 / 60 秒窗口、优先级与限流状态；当前标签页的速率、类型、P95 与日志只保留最近 15 分钟、最多 1200 条。

两者都不记录查询参数、请求正文、Cookie 或响应内容。浏览器不提供单个 userscript 的独占 CPU 或内存数据，监控只能说明当前页面观察到的活动。
